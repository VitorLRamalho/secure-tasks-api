# Security Policy

## Supported versions

Only the `main` branch receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report privately at
https://github.com/VitorLRamalho/secure-tasks-api/security/advisories/new
or by email to <vitorlramalho@gmail.com>. You will get an answer within 72 hours.

## Security controls in this repository

See the README ("What is enforced") and `docs/findings.md`.
