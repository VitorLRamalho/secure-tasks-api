# Security Policy

## Supported versions

Only the `main` branch receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting
(Security → Report a vulnerability) or email SEU_EMAIL. You will get an answer
within 72 hours. Reports are triaged with CVSS v3.1 and fixed in order of severity.

## Security controls in this repository

See the README ("What is enforced") and `docs/findings.md`.
